# Overview

IIUI Journal was an independent student platform created to improve communication and knowledge sharing within the International Islamic University Islamabad (IIUI) community.

The goal was to solve common problems faced by students by providing one place where they could:

- Ask academic questions
- Share university announcements
- Publish blogs
- Upload and download past papers

Despite being available for only **two days**, the platform experienced remarkable growth, demonstrating a strong demand for a centralized student community.

---

# Project Impact

One of the most exciting parts of this project wasn't just the technology—it was the adoption.

Within just **48 hours** of launch, IIUI Journal achieved:

-  **1,500+ student registrations**
-  **1,300+ active users**
-  Hundreds of shared academic resources
-  An active Q&A community
-  Student-driven announcement sharing

The rapid adoption highlighted a significant need for a platform that connected students beyond traditional university communication channels.

---

# Project Status

After approximately **two days** of operation, the platform was taken offline following action by the university administration.

As a result, development stopped and the website is no longer publicly available.

This repository is preserved as a portfolio project demonstrating the application's architecture, features, and the real-world impact it achieved during its short lifespan.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/yourusername/iiui_journal.git

cd iiui_journal
```

---

## Install Dependencies

```bash
npm install
```

---

## Environment Variables

Create a `.env` file.

```env
PORT=3000

MONGO_URI=your_mongodb_connection_string

SESSION_SECRET=your_secret_key
```

---

## Run Development Server

```bash
npm start
```

or

```bash
npm run dev
```
